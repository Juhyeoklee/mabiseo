# 마비서 (`mabiseo`) — 뼈대

> 2026-09-28 · Cowork. **뼈대다 — 결정이 아니라 출발점.** 결정이 바뀌면 그 자리를 고친다(계약이라 사용자 판정). 열린 것은 §5에 모았다.
> 로드맵과 상태는 이 문서에 적지 않는다 — GitHub 마일스톤(M0~M3)과 이슈에서 읽는다. 작업 방식은 `CLAUDE.md`.

## 1. 한 줄

집 와이파이 안에서 **아이폰으로 자연어 할 일**을 보내면, **Windows PC의 데스크탑 앱**이 AI 에이전트로 **마비노기 모바일 공식 AI 커넥터**를 불러 수행하고 진행을 폰에 실시간으로 돌려준다.

## 2. 확정된 것

| 항목 | 결정 |
|---|---|
| 요청 | 자연어 — 데스크탑의 에이전트가 해석·실행 |
| 범위 | 집 안(같은 와이파이)만. 데스크탑이 곧 서버 |
| 모바일 | iOS 네이티브 (SwiftUI) |
| 데스크탑 | Windows (게임·커넥터 옆). 제안: Electron + Claude Agent SDK (TS) |
| 개발 | 맥에서 개발, Windows는 실행만 |
| 에이전트 | Claude Agent SDK(TS). 도구는 `tools/` 카탈로그를 in-process MCP 서버로 노출. 개발 단계 인증은 개발자의 API 키(환경 변수 · 판정 2026-09-29). 최종 사용자의 인증 방식은 열린 것(§5). 모델은 SDK 기본값 |

**외부 제약** — 넥슨 공지 [AI 커넥터 사전 안내](https://mabinogimobile.nexon.com/News/Notice/3541579) (2026-09-09 · Beta)

| | |
|---|---|
| 환경 | **PC 클라이언트 전용.** [환경 설정 → 게임 → AI 커넥터] 토글(기본 꺼짐) |
| 연결 | 토글을 켜면 **클라이언트가 PC에 설치된 AI 도구를 찾아 연결을 자동 등록**한다(공지). 무엇을 등록하는지는 불명 — 한 사용자 환경에서는 `~/.claude.json`에 아무것도 안 생겼다(커뮤니티) |

| 세션 | **CLI는 파이프 상대가 같은 로그인 세션·같은 사용자인지 검사한다**(실측 2026-09-29 · 바이너리의 `ValidateClientSameSessionAndOwner`). SSH 등 세션 0에서 부르면 게임이 떠 있어도 `{"pipe":"disconnected","reason":"game_off"}`. 데스크탑 앱과 원격 실행기는 로그인 세션에서 돌아야 한다. **게임이 꺼져 있으면 어느 명령이든 약 5초를 기다린 뒤 종료 코드 5로 같은 끊김 값을 낸다**(실측 2026-09-29 · `recordings/game-off/`) |
| 토글 | 7일 미사용 시 자동 OFF |
| 물어보기 (무료) | 캐릭터 상태·능력치 · 위치·날씨·시간 · 재화·인벤토리 무게 · 퀘스트·일일/주간 미션 · 주변 NPC·플레이어 · 재료·악보·악기 목록 |
| 맡기기 (정령의 날개 소모) | 채집·가공·제작 · 가공 확인·수령 · 연주·악기 변경 · 행동 중단·일어나기. **날개는 채집·가공 등록·제작 호출 1회당 5개 — 수량 무관**(채집 1회 최대 100개) |
| 긴 작업 | 채집 100개 2~15분 · **활동은 한 번에 하나**(새 활동이 이전 것을 취소) |
| 1시간 팝업 | 계속 쓰면 1시간마다 **PC 화면에** 확인 팝업 — **확인해야 이후 요청이 처리된다** |
| 동작 안 함 | 로그인 화면 · 캐릭터 선택 화면. 캐릭터 선택 화면에서 `status`는 `connected`이고 명령은 `{"error":"not_in_game"}`(실측 2026-09-29) — 게임 안인지는 `status`로는 모른다 |
| 거부 응답 | 종료 코드 0에 `{"error":<코드>,"message":<영문>}` — `not_sitting` · `invalid_state` · `not_found` · `not_in_game`(실측 2026-09-29 · `recordings/`). 날개 부족 · 가방 가득은 미녹화 |
| 채팅 | **승인은 게임이 아니라 AI 도구 몫.** CLI `write_chat`은 확인 창 없이 즉시 전송된다(실측 2026-09-29 · `capabilities`의 `requiresConfirm`은 도구가 걸어야 할 표시). 데스크탑이 폰 승인 없이는 부르지 않는다 · AI 아이콘 표시 · 도배는 이용 제한 |
| 불가 | 거래소 · 성장 자동 플레이 · 결제·캐시샵 · 길드 운영 · 1:1 대화 · 버리기·분해 · 외부 메신저/SNS 연동 |
| 그 밖 | 다른 유저 이름·채팅은 안 넘어온다 · AI 이용료는 사용자 부담 · **책임은 일차적으로 사용자** — 운영정책 11조(9/17 신설 · 허용되지 않은 방식의 기능 변조는 제재) |

**팝업 자동 클릭은 넣지 않는다** — 방치 파밍 방지 장치의 우회다.

## 3. 구조

```
mabiseo/
├── protocol/   메시지 스키마 — 두 언어가 공유하는 유일한 계약 (→ TS 타입 · Swift Codable)
├── desktop/    Electron + TS
│   ├── agent/       Agent SDK 호스트 (세션 · 스트림 · 도구 승인 콜백)
│   ├── connector/   CLI 어댑터 — 실행 · 응답 정규화 · 한글 인코딩 / 실물(Windows) ↔ 가짜(녹화 재생)
│   ├── tools/       에이전트에 내놓는 도구 + 보호 장치(날개 예산 · 가방 · 재시도 차단)
│   ├── jobs/        긴 활동 관리 — 한 번에 하나
│   └── server/      LAN WebSocket + Bonjour 광고 + 페어링
└── ios/        SwiftUI — 발견·페어링 · 대화
```

## 5. 열린 것

- 토글의 「자동 등록」이 무엇인가 — 우리는 CLI를 직접 부르므로 **몰라도 막히지 않는다.** 공식 등록분과 겹치면 한쪽만 쓴다 → **M0**
- 1시간 팝업을 감지할 수 있는가 — `blocked` + `kind`로 온다는 추정만 있다 → **M0**
- 사용자 인증 방식 — 사용자가 자기 API 키를 넣는가, 자기 Claude 구독을 연동하는가. Agent SDK 문서는 사전 승인 없는 제3자 제품의 claude.ai 로그인 사용을 금지한다 → 재판정 #11
- 에이전트 모델 선택 — SDK 기본값으로 시작. 비용과 도구 호출 순서를 보고 정한다
- Windows 실행 방식 — 개발 중엔 `git pull` + 실행, 패키징은 나중
- 승인 경계 — **기본안: 물어보기는 바로, 맡기기(날개 소모)는 폰에서 승인.** 일정량 이하는 묻지 않을지는 써보고 정한다
- 제3자 래퍼 앱에 대한 정책 — 공지에 언급 없음. FAQ가 나오면 확인
